MatAnyone2 GUI v1.0
By Felipe Esquivel Reed
felipeer@gmail.com


This is a graphical interface to process videos using MatAnyone2 (https://github.com/pq-yang/MatAnyone2) automatic matte extraction tool. This don't work with MatAnyone.

This tool is written in Python and requires some libraries that can be obtained with the instruction: 

pip install PyQt5 opencv-python numpy

To install this tool just copy the file inside the MatAnyone2 folder.
